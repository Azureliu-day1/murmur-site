Vibe Coding · 对着 AI 说话

对 Claude Code
口述需求。

光标停在终端的提示符后面,按右 ⌘ 说: 「把这个 function 改成 async,再加个 retry」。 松手,这句话就出现在提示符后面。 Cursor、Codex 的输入框里也一样。 Murmur 是系统级听写,不需要插件,也不用配置。

中英夹着说。变量名、库名、报错保留英文,中间的中文照常落下。
听错的库名改一次。把听错的库名或 API 名改对,它会进词典,下次直接听对。
常用 prompt 存成快捷短语。说触发词,落下整段模板。每天要交代的规矩不用再敲。
查 API 名字不用切窗口。开启随心问后,按 fn 说出问题,答案落在光标处。
选中一段代码,说怎么改。按右 ⌃ 说出改法,改好的代码落回原处。
在代码编辑器里不改标识符。它认得出前台是编辑器,落字时换用另一套规则。

Local · 数据在哪

录音只存在
你的 Mac 上。

我们的服务器只管账号、登录和订阅。录音、转写、历史和词典都存在你的 Mac 上。 用云端识别时,音频直接发给你选的那家识别服务,不经过我们。 用本机识别时,音频不出这台电脑。

Promises · 承诺

四条承诺。

说过的话不丢

每次听写都存一份录音和一条历史。云端出错或识别错了,可以在历史里换个模型重新识别。

出错会告诉你

翻译失败时,屏幕上会提示。麦克风没收到声音,也会当场提示。它不会往你的窗口里塞乱码。

音频去哪看得到

用本机识别时,音频不出这台电脑。用云端时,设置里写着发给了哪家、发了什么。

数字是实测的

「松手到出字」的延迟写的是实测中位数。哪一档听得不准,在菜单里换一档就行。

Lecture · 长录音

上课开长录音。

开长录音后,字幕浮窗盖在全屏网课上面,边放边出字。 要看译文,可以开双栏。 字幕只是预览,中途断了也不影响录音。 录完后完整转写存进历史,分得出谁在说话。

实时字幕预览 · 录完存进历史

免费档每月可以录 30 分钟长录音。

Details · 顺手的小事

顺手的小功能。

词典自动加词。你改对过的专有名词会进词典,下次直接听对。没把握的词不加。
快捷短语。说一个触发词,落下整段地址或常用回复。这一步不经过大模型。
分应用语气。落进邮件时,措辞比落进微信正式。在代码编辑器里不改你的标识符。
在历史里改错字。每条听写都留着原文和录音。你改过的字,以后识别时会参照。
悄悄话模式。在图书馆用气声说话,它先把声音放大再识别。
「半小时后提醒我」。说这一句就设好提醒,到点弹出。这句在本机处理,不花额度,断网也能用。
参考屏幕上的专名。开始录音时,它读一次前台窗口的文字,找出专有名词帮忙识别。不截屏,这些词也不进词典。细节见「你的数据在哪」。
Questions · 常见问题
我的录音会被传到哪里?

录音、转写、历史和词典都存在你的 Mac 上。我们的服务器只处理账号和订阅。用云端识别时,音频直接发给那一家识别服务,不经过我们的服务器。用我们代付的免费额度时也是这样。有一个例外:用免费额度时,整理用的文字会先经过我们的服务器,再转给模型厂商。用本机识别时,什么都不出电脑。词典里的专有名词会随请求发给识别服务,帮它听对这些词。这些在设置里都写着。

断网了怎么办?

断网或额度用完时,会自动换成本机识别。本机识别慢一些,中英混说没那么准,录音照样保存。联网后,可以在历史里用云端档位重新识别任何一条。

支持哪些语言?

中文、英文,以及一句话里中英夹着说。带粤语、川渝、吴语口音的中文有专门的档位,目前在内测。

需要自己配 API Key 吗?

不需要。云端额度现在是邀请制,拿到名额并登录后就有免费额度。免费额度的云端费用由我们付。用完后自动换成本机识别,不会停下来让你付费。
