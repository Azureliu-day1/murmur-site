Privacy · 你的数据在哪

录音、历史和词典存在你的 Mac 上。 云端识别时,音频直接发给你选的那一档的识别服务商,不经过我们的服务器。 登录后没填自己的 Key 时,整理、翻译、随心问和口述编辑的文字先经过我们的服务器,再转给大模型;服务器不存原文。 下面把每一类数据的去向、存放和删除写清楚,每一条都给出你亲手核实的办法。

录音你的声音

识别时直连你所选档位对应的那一家识别服务商 —— 各档位背后是哪家,以 App 内「隐私」一节的实时说明为准(它随档位演进而更新,比这页新);选「本机识别」时,音频一个字节都不出这台电脑。 录音文件存在你 Mac 本地,默认保留 30 天供重跑,之后自动删除。

设置里可把保留期改成 7 天或「不保存」;删掉本地文件夹即彻底删除。本机识别时音频不出电脑;开着整理时,文字仍会发给大模型。想让说的内容完全不出电脑:选本机识别,整理设成「不动」,也不用翻译、随心问和口述编辑。

转写与整理的文字你说的内容

开着 AI 整理,或用翻译、随心问、口述编辑时,转写文字会交给大模型处理一次(口述编辑还带上你选中的那段)。自己填了 Key 就直连那家厂商;登录后没填 Key、用免费额度时,先经过我们的服务器再转给大模型,服务器不存原文。App 内「隐私」一节按你当前设置写着走哪条路。 成品与历史记录存在你 Mac 本地的数据库里,不整份同步到任何云。 「个人风格」默认关。打开后,每次整理会从最近的听写记录里挑最多 3 条「原话 → 整理稿」当范例,随整理请求一起发出。

关掉整理(「不动·直出转写」档)则文字不经过任何大模型;历史可单条删、可全清,保留期可设。

词典你的专有名词

为了听对你常说的名字,词典里的词会随每次识别请求发给识别服务商;开着整理时,也随整理请求发给大模型。这件事写在设置里的明面上,不藏在条款里。

词典条目随时可删;删掉后不再随请求发送。

屏幕上下文录音那一刻的前台窗口文字

录音那一刻读一次前台窗口的可见文字(走辅助功能,不截屏),用来矫正专有名词。选了云端识别时,从中抽出的专名随录音发给识别服务商。 开着整理,或用翻译、随心问时,屏幕文字的节选(最多 1500 字)随转写发给大模型;用免费额度时先经过我们的服务器,自己填 Key 时直连那家厂商。 在本机不落库、不落盘、不进日志,屏幕上的词也永不进词典。

默认开。在 设置 → 识别 关掉「参考屏幕上的文字纠正专名」;本机识别且不整理时根本不读。

API Key 与设置你的凭证

API Key 存在 macOS 钥匙串(系统级加密),设置存在系统偏好——都只在本机,我们看不到、也收不到。

删除 App 时按系统惯例清理;Key 可在设置里随时清空。

Never · 我们不做的事

写下来,就是承诺不做。

✕

不经手你的音频。云端识别的音频从你的 Mac 直达识别服务商,不经过我们的服务器。整理用的文字有例外,见下面「登录之后」一节。

✕

不做行为埋点。App 里没有统计 SDK,不把你在哪个 App 里说话报给我们。登录后,用到云端服务的那句会报一次字数(长录音报时长),用来算额度,不带原文,见下面「登录之后」一节。

✕

不卖数据、不共享数据。没有广告主,没有「合作伙伴」,你的数据不是商品。

✕

官网没有统计脚本。没有埋点、没有广告。登录页和试一试页为了登录和防刷会加载第三方脚本,写在下面「官网」一节,你可以打开浏览器的网络面板核实。

Verify · 不用信我们,自己看

三件你现在就能亲手核实的事。

① 数据就在这个文件夹里

~/Library/Application Support/Murmur/ —— 录音和你说过的每一个字都在这,随时打开看。删掉,就是真的删掉了。

② App 会连哪些地方

用「小火苗 LuLu」这类免费防火墙观察 Murmur 的网络连接,你会看到这几类:你选的识别 / 大模型服务商(自己填了联网搜索的 Key 时还有那一家);登录后还有我们的服务器(登录、额度、免费额度的识别通行证和整理转发);打开设置的「整理」页时,读一次 OpenRouter 的公开模型清单,不带你的内容。

③ 每一条的去向,历史页里都写着

App 内历史页的「数据去哪了」按你当前设置如实列出:这条用了哪家识别、文字有没有过大模型、屏幕上下文开没开。

Account · 登录之后

不登录时,App 不连我们的服务器。

登录后,我们的服务器做这几件事:

① 登录、额度和订阅状态。② 每说完一句、用到了云端服务时,报一次这句的字数和类型(听写或随心问;长录音报时长),不带原文。③ 用免费额度识别时,每次开录换一张一次性通行证,所以服务器知道你此刻在录音;音频仍然直连识别服务商。④ 用免费额度(没填自己的 Key)时,整理、翻译、随心问和口述编辑的文字先经过服务器,再转给大模型。同一个请求里还有词典、屏幕节选;开了个人风格时,还有最多 3 条历史例句。服务器只转发和记账,不存原文,日志里也没有正文。

录音不上传。历史不整份上传,只有开了个人风格时,整理请求里带最多 3 条。这一页每次修改,页面底部都会留下日期。

Website · 官网

这个网站没有统计脚本,也没有广告。下面几处会把东西交给我们的服务器或第三方:

① 申请名额的表单:存你的邮箱、你写的那句话和界面语言;另存一个加盐散列过的网络地址,只用来限制提交次数。② 网页试整理:你贴的文字发到我们的服务器,再转给大模型整理,服务器不存原文。③ 登录页和试一试页从 cdn.jsdelivr.net 加载登录用的脚本;防刷验证开着时,这两页还会加载 Cloudflare Turnstile。付款完成页从 Google Fonts 加载字体。
