录音你的声音

识别时直连你所选档位对应的那一家识别服务商:用免费额度的云端识别时,音频发给 Soniox(美国);自己填了 Key 时,发给你填 Key 的那一家。选「本机识别」时,音频不出这台电脑;个别语言系统不支持离线识别时,可能由 Apple 处理。 录音文件存在你 Mac 本地,默认保留 30 天供重跑,之后自动删除。

设置里可把保留期改成 7 天或「不保存」;删掉本地文件夹即彻底删除。本机识别时音频不出电脑;开着整理时,文字仍会发给大模型。想让说的内容完全不出电脑:选本机识别,整理设成「不动」,也不用翻译、随心问和口述编辑。

转写与整理的文字你说的内容

开着 AI 整理,或用翻译、随心问、口述编辑时,转写文字会交给大模型处理一次(口述编辑还带上你选中的那段)。自己填了 Key 就直连那家厂商;登录后没填 Key、用免费额度时,先经过我们的服务器,再转给 DeepSeek(中国)处理,我们的服务器不存原文。App 历史页的「数据去哪了」按你当前设置写着走哪条路。 开了「提示词技能」时,在 AI 工具里用听写键说的够长的一句,转写文字会多发一次给同一条通道和同一家厂商,用来判断是哪种需求;不发录音,不发你在哪个窗口。 成品与历史记录存在你 Mac 本地的数据库里,不整份同步到任何云。 「个人风格」默认关。打开后,每次整理会从最近的听写记录里挑最多 3 条「原话 → 整理稿」当范例,随整理请求一起发出。

关掉整理(「不动·直出转写」档)则文字不经过任何大模型。历史可以单条删。想一次清空:在 设置 → 系统 把「保留文字」设成「不保存」,再点「立即按保留期清理」。保留期可设。

词典你的专有名词

为了听对你常说的名字,词典里的词会随每次识别请求发给识别服务商;开着整理时,也随整理请求发给大模型。这件事写在设置里的明面上,不藏在条款里。

词典条目随时可删;删掉后不再随请求发送。

打过的词拼音输入法学到的词

存在这台 Mac 上:~/Library/Application Support/Murmur/lexicon.sqlite。学词默认开着。密码框与拒绝名单里的 App 一律不记。 听写时,这些词当提示词随识别请求发给识别服务商。这和上面「词典」一行走同一条路。选本机识别时不出机。第一版不跨设备。 按 ⌥⇧Space 让 AI 整理这句时,词典里登记的词和学到的词里与这句沾边的(最多 500 个)随整理请求出机。选本机识别也一样。

设置 → 输入法 → 「我打过的词(输入法学的)」卡:关「学我平时打的字」,之后不再学新词;关「允许 AI 参考我的用词」,AI 整理时一个词都不发。设置 → 系统 → 「清除数据…」一键清掉已学的词。联想开关「联想(根据你打过的词)」在同一张卡上。

屏幕上下文录音那一刻的前台窗口文字

录音那一刻读一次前台窗口的可见文字(走辅助功能,不截屏),用来矫正专有名词。选了云端识别时,从中抽出的专名随录音发给识别服务商。 开着整理,或用翻译、随心问时,屏幕文字的节选(最多 1500 字)随转写发给模型厂商;用免费额度时先经过我们的服务器,自己填 Key 时直连那家厂商。 在本机不落库、不落盘、不进日志,屏幕上的词也永不进词典。

新装默认关;从旧版升级的保持你原来的选择。在 设置 → 识别 开关「参考屏幕上的文字纠正专名」;本机识别且不整理时根本不读。

登录凭据、API Key 与设置你的凭证

登录凭据存在 macOS 钥匙串。你自己填了 API Key 的话,它也存在钥匙串,只在本机,我们收不到。设置存在系统偏好里。

删除 App 时按系统惯例清理;Key 可在设置里随时清空。

我们不做的事

写下来,就是承诺不做。

✕

不经手你的音频。云端识别的音频从你的 Mac 直达识别服务商,不经过我们的服务器。整理用的文字有例外,见下面「登录之后」一节。

✕

不做行为埋点。App 里没有统计 SDK,不把你在哪个 App 里说话报给我们。登录后每说完一句(本机识别的那句也算),会报这句的字数、说话时长和走了哪条路,用来算额度,不带原文,见下面「登录之后」一节。

✕

不卖数据。只交给为提供服务所必需的处理方(名单见下面「登录之后」一节)。没有广告主,你的数据不是商品。

✕

官网没有统计脚本。没有埋点、没有广告。登录页、试一试页和技能页的脚本由本站自托管,只有防刷验证开着时加载 Cloudflare 的验证脚本,写在下面「官网」一节,你可以打开浏览器的网络面板核实。

不用信我们,自己看

三件你现在就能亲手核实的事。

① 数据就在这个文件夹里

~/Library/Application Support/Murmur/ —— 录音和你说过的每一个字都在这,随时打开看。删掉,就是真的删掉了。

② App 会连哪些地方

用「小火苗 LuLu」这类免费防火墙观察 Murmur 的网络连接,你会看到这几类:你选的识别 / 大模型服务商(自己填了联网搜索的 Key 时还有那一家);我们的服务器(登录、额度、公开配置、免费额度的识别通行证和整理转发);官网(每天读一次版本文件);下载 Rime 词库或句子模型时还有 GitHub;打开设置的「整理」页时,读一次 OpenRouter 的公开模型清单,不带你的内容。

③ 每一条的去向,历史页里都写着

App 内历史页的「数据去哪了」按你当前设置如实列出:这条用了哪家识别、文字有没有过大模型、屏幕上下文开没开。

登录之后

不登录时,App 也会连我们的服务器读公开配置:只在 App 在前台、或听写后 5 分钟内读,间隔由服务器在 60–3600 秒之间调(默认 5 分钟)。这个请求里没有你的身份,也没有你说的内容。另外每天读一次官网的版本文件。

登录后,我们的服务器还做这几件事:

① 登录、额度和公开配置(登录后改走带身份的那份)。② 每说完一句,报一次:字数、说话时长、是听写还是随心问、走了哪条路(本机 / 自己的 Key / 免费额度)、发生的时间。本机识别的那句也报,不扣额度。不带原文。③ 用免费额度识别时,每次开录换一张一次性通行证,所以服务器知道你此刻在录音;音频仍然直连识别服务商。④ 用免费额度(没填自己的 Key)时,整理、翻译、随心问和口述编辑的文字先经过服务器,再转给模型厂商。同一个请求里还有词典、屏幕节选(最多 1500 字);开了个人风格时,还有最多 3 条历史例句;开了提示词技能时,AI 工具里那句会多发一次。服务器只转发和记账,不存原文,日志里也没有正文。⑤ 开了输入法的云候选(默认关)时,还没上屏的拼音经我们的服务器转给 DeepSeek(中国);只发拼音。

录音不上传。历史不整份上传,只有开了个人风格时,整理请求里带最多 3 条。词典会随识别请求和整理请求整份发出,见上面「词典」一行。打过的词不整份上传,只有按 ⌥⇧Space 整理时带上与这句沾边的那些,见上面「打过的词」一行。这一页每次修改,页面底部都会留下日期。

处理方和所在地。用免费额度时,整理、翻译、随心问和口述编辑的文字由 DeepSeek(中国)处理;输入法云候选的拼音由 DeepSeek(中国)处理;云端识别的音频发给 Soniox(美国);账号和用量存在 Supabase(新加坡);邮件经 Resend 发出。自己填了 Key 时,文字或音频直接发给你填 Key 的那一家。App 的请求在新加坡处理,网页和旧版 App 可能经由澳大利亚(悉尼)中转;数据库在新加坡。

服务器存什么、存多久。我们的服务器存:你的邮箱;额度账本(每一笔的时间、字数、说话时长、类型和走了哪条路);订阅状态;申请名额时的表单(邮箱、留言、界面语言、加盐散列过的网络地址和浏览器类型简写)。这些保留到你删除账号后 30 天,然后删掉。要删账号或要一份副本,写信到 contact@maobenbeginner.com 就行。

发生影响你的数据泄露,我们会及时通知你。

官网

这个网站没有统计脚本,也没有广告。下面几处会把东西交给我们的服务器或第三方:

① 申请名额的表单:存你的邮箱、你写的那句话、界面语言和浏览器类型简写;另存一个加盐散列过的网络地址,只用来限制提交次数。提交即在我们的账号系统里为这个邮箱建一个身份;表单内容经 Resend 转发到我们的邮箱。② 网页试整理:你贴的文字发到我们的服务器,再转给大模型整理,服务器不存原文。③ 登录页、试一试页和技能页的脚本都由本站自托管;防刷验证开着时,这三页还会加载 Cloudflare Turnstile。④ 价格页读取你在本站的登录状态,用来把付款对上你的账号:点付款时,账号编号和邮箱随付款链接交给 Stripe。
