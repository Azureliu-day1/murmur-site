Changelog

Murmur 0.53

The biggest change in this version: Murmur now includes a Pinyin input method. The list below starts with what you are most likely to notice.

New·Privacy and security·Fixed·How to upgrade

0.53.1 · October 29

  • Sign in with just your email: with no account yet, Murmur applies for you and goes straight to the code step.
  • Change your dictation key right inside onboarding; Accessibility setup is more reliable.
  • Drag the live-caption window by its header; captions are easier to read.
  • Steadier lecture recording: transcription resumes after a dropped connection, and long silences no longer cause endless reconnects.
  • Your account card shows this month's lecture time; on paid plans, running out stops only lecture recording.
  • Security hardening: Murmur only talks to its own genuine components, and diagnostics no longer record what you said.

New

Pinyin input method

  • Murmur ships with its own Pinyin input method, which shares one dictionary with dictation.
  • Install, update and uninstall it in Settings → Input Method. Dictation works without it.
  • Full Pinyin, Flypy and Ziranma double Pinyin. Nine fuzzy Pinyin pairs; tick only the ones you mix up.
  • Full-width Chinese punctuation; URLs and email addresses stay in English.
  • Press Delete within 1.5 seconds of a commit and the whole word turns back into Pinyin.
  • A word you pick once moves up next time.
  • While typing, press ⌥⇧Space to have AI clean up the sentence you are typing.
  • Cloud candidates (preview): press ⌥↩ and the cloud suggests a whole sentence. Off by default, sign-in required.

Prompt skills

  • In AI coding tools, AI chat tools and some AI desktop apps, press the dictation key and say what you want.
  • What goes in is your own words, cleaned up. When Murmur can tell what you want done, up to three steps are added at the end.
  • Twelve skills: build a feature, fix a bug, change or refactor code, explain code, review code, plan the work, write tests, research, write, decide, summarize, reply.
  • Off by default; turn it on in Settings → Cleanup. It does not run in terminals and never presses send for you.

More accurate cleanup

  • Technical terms and names that were clearly misheard are corrected during cleanup.
  • Chinese cleanup always uses full-width punctuation.
  • Cleanup by scene: the tone follows the app the text lands in. Email reads like email, and chat stays conversational.

Long recording

  • You can try one free long recording of up to 3 minutes. It stops on its own at 3 minutes and keeps what was recorded. Suited to meetings and lectures.
  • With your own recognition service key, you can turn on floating captions and the second-column translation.
  • Before it starts, Murmur reminds you to get consent from the people in the room.

Easier to find

  • A new Features page in the main window: one line per feature, one click to its setting. It opens once by itself after you upgrade.
  • Settings now has five tabs; all input method settings are on the Input Method tab.
  • About in the menu bar shows the version and can check for updates. Murmur checks the website once a day and shows a note in the menu bar when a new version is out. It never downloads by itself.
  • Every history entry has a Fix button. Fix it and press ⌘↩ to save.

Privacy and security

  • "Use the text on screen to get proper nouns right" is now off by default on new installs. If you already use Murmur, your choice is kept.
  • The setting now explains what is sent when it is on, who receives it, and which country the data is in.
  • Murmur never reads the screen in password fields, password managers, or while secure input is on.
  • "Where your data goes" on the History page names the processor and country for each step.
  • Text that Murmur puts on the clipboard is marked as temporary, which asks clipboard managers not to keep it.
  • File permissions on history, recordings and word lists have been tightened so only your account can read or write them.

Fixed

  • In some AI desktop apps, a sentence was sometimes pasted twice.
  • AirPods switching to call mode no longer shows "input device changed". It shows only when the device really changes, and hides after 2 seconds.
  • With the n / l fuzzy pair on, typing a single l no longer gives 嗯.
  • Tags such as </transcript> no longer slip into cleaned-up text.
  • Text fields where the selection cannot be read now get the text directly, with no manual ⌘V.
  • If you switch to another window and back to the original field, the text now goes in within 60 seconds.
  • "Inserted" shows only after it is checked. Otherwise it says "Inserted (not checked)".
  • If the microphone picks up no sound while recording, the capsule says so.
  • The English interface no longer shows Chinese error messages.
  • After a force quit or crash, the unfinished sentence is kept in history.

How to upgrade

  • From 0.52: download the new version from the website, unzip it and drag it into Applications to replace the old one.
  • 0.52 cannot check for updates by itself. From 0.53 on, About in the menu bar can.
  • Requires macOS 26 or later on a Mac with Apple silicon.
  • Questions? Email support@day1aifitness.com.
