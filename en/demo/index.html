Demo

Type Pinyin in your browser

This is a demo, not the real input method. The word list was written by hand for this page and has only a few hundred words. The real input method installs with Murmur. See the Pinyin section on the home page.

Chinese

The candidate window is drawn like the real one: 5 per page, with the current number in coral.

  • 1to5pick a candidate
  • Spacecommit the highlighted one (the first by default)
  • Deleteonce within 1.5 s of a commit puts the word back as Pinyin
  • Shifttap alone to switch Chinese and English; half-typed Pinyin is kept as letters
  • -=previous page, next page
  • ,.commit the highlighted one with the punctuation
  • Returncommit the Pinyin letters as typed
  • Escclear the Pinyin; closes next-word suggestions first

Delete does not put back a next-word pick, punctuation, or letters committed with Return.

Want it on your Mac? Download the Mac app, then install it from Settings → Input Method → the “Input method” card.
