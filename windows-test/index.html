Windows 探针

一个小工具,测你的 Windows 电脑能不能跑 Murmur。它不是正式版。

免安装,下载后双击就能用。不需要管理员,不改任何设置。

下载 x64 版大多数电脑选这个 下载 ARM64 版骁龙等 ARM 处理器

不知道选哪个:打开「设置 → 系统 → 系统信息」,看「系统类型」。写着 ARM 的选 ARM64,其余选 x64。文件约 60 MB,自带运行环境。

弹出蓝色警告时

Windows 可能显示「Windows 已保护你的电脑」。点「更多信息」,再点「仍要运行」。

如果直接被拦下、没有「仍要运行」,截个图发给我们。这本身就是测试结果。

测试步骤

  1. 双击运行。窗口顶部会显示这台电脑的信息。
  2. 点「录 3 秒」,对着麦克风说几句话,听回放。
  3. 按住键盘右边的 Alt,看灯亮不亮。再按一次 Ctrl + Alt + 空格。
  4. 打开记事本,点「3 秒后往当前窗口落字」,3 秒内切到记事本。
  5. 点「测网络」,再点「生成报告」,把复制好的报告发回来。

报告不含用户名、电脑名、文件和网络地址。所有文件和校验值见发布页。
