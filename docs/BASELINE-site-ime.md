# 基调 · 网站输入法区(2026-11-01,Wei「两样都要」+「你去做」)

## 目标(一句话)
陌生人在网站上 30 秒看懂「Murmur 自带的拼音输入法能干什么、AI 在哪」,能在网页里上手试,并有一套能发出去的宣传图。

## 做 / 不做
- 做:
  1. 产品页 /pinyin/ 与 /en/pinyin/(新):主图 + 「和听写共用一本词典」+「打得准」+「AI 整理这句(一次键,六个动作,可改键)」+「云候选(预览)」+「顺手的小东西」(退格退回 / 智能标点 / 双拼模糊音 / 候选窗外观 / Emoji 快捷短语)+ 装法(设置 → 输入法 一键装,不装不影响听写)+ 行动区(下载 Mac 版 / 在网页里自由试打 → /demo/)。
  2. 可上手的演示(零内联,照 /mobile/ 的做法):A 打字演示(复用 /demo/ 引擎 demo.js 的候选逻辑,一个输入框 + 候选条,预置三句);B AI 卡演示(HTML 状态机:打到一半按「AI 整理」→ 正在整理 → 结果 + 六个 chip 可切 → 用上);C 退格退回演示(上屏后 1.5 s 内退格整词退回)。
  3. 宣传图中英各 7 张(主图 / AI 卡特写 / 云候选特写 / 快捷键卡 / 社交竖图 ×2 / OG),PNG 母版留档,WebP 进站。
  4. 首页 #pinyin 节加「看看拼音输入法 →」指向 /pinyin/;页脚 nav-wide 页加「拼音输入法」。
- 不做:词库同步、免登录 AI、延迟承诺、上线日期、通知;/demo/ 页不重做(只从新页链接过去)。

## 文案红线(builder 照抄,不许扩)
- 可写(0.53.1 已发布事实):随包、设置 → 输入法 一键安装 / 更新 / 卸载,不装不影响听写;全拼 / 小鹤 / 自然码;模糊音 9 对只勾你分不清的;中文标点全角、数字后半角、网址邮箱直走英文;上屏后 1.5 秒内退格整词退回拼音重选;选过的词下次排前面;和听写共用一本词典(教它听对的名字,打字时出现在候选;打过的词说话时也认得);125 句口语自测首选正确 80.0%(首页已有口径);⌥⇧Space 让 AI 整理正在打的这句(整理 / 正式 / 随意 / 续写 / 英文 / 问,按一次就出,再按一次用上;快捷键可在设置里改);云候选(预览,默认关,要登录):打开后停顿就让云端猜整句,Tab 上屏,云端结果只在和本机不同时出现;候选窗字号 / 强调色 / 横竖排;Emoji 面板与快捷短语(默认关 / 自己加);Spotlight 自动切苹果拼音;⌃Space 切换。
- 云候选必须带一句隐私实话:「打开后,还没上屏的拼音会发到 Murmur 服务器并转给第三方模型服务来猜整句;默认关。」⛔ 不许写「不上传」。
- ⛔ 不许写:词库跨设备同步、免登录 AI、具体秒数、上线日期、通知你、供应商名、内部代号;图里不许有「样例 / 模拟器 / 内测 / ——」、版本号、日期、真人名、邮箱。
- AI 整理:写「登录后可用」,不写免费 / 额度数字。

## 用户可见的验收
1. /pinyin/ 与 /en/pinyin/:陌生人 30 秒看懂「自带拼音输入法 + AI 在哪 + 怎么装」。
2. 三个演示都能在页面上走完,键盘可操作,减少动效可用,不进视口不跑。
3. 宣传图 14 张单看就明白是「Murmur 的拼音输入法」,风格与网站一致(浅灰底 + 珊瑚小面积,编辑部 × 工具面板),外框全用 CSS 画,无 AI 感。
4. 门:copy-lint PASS、所有请求 200、控制台 0 错、scan-public-push PASS、375 / 1280 截图中英各一。
